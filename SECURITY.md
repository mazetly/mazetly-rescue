# Security policy

Mazetly Rescue handles backups and the keys that open them. If you find a
vulnerability, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/mazetly/mazetly-rescue/security/advisories/new),
not in a public issue. You will get an answer within a week.

Most useful are reports about a kit or a repository being readable or writable
by someone who should not have access, a restore running something other than
what was backed up, or a key leaking (command line, logs, files left behind).

---

*Politique de sécurité.* Mazetly Rescue manipule des sauvegardes et les clés
qui les ouvrent. Si vous trouvez une vulnérabilité, signalez-la en privé par le
[signalement privé de GitHub](https://github.com/mazetly/mazetly-rescue/security/advisories/new),
pas dans une issue publique. Vous aurez une réponse sous une semaine.
